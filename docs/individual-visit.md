# Индивидуальный визит: расчёт для проверки

Рабочая ветка продолжает `fix/audit-2026-10-22`; публикация в main не выполняется. 22.10.2026 пользователь передал фрагмент последнего обсуждения, который хранится только локально в материалах проекта. Восстановлены предварительные мужские цены и длительности. После просмотра доплаты 7 300 ₽ пользователь попросил пересчитать её: полная стоимость нескольких пересекающих записей завышала плату за короткий визит.

## Где доступно

Опция доступна только для `men-mani` на отдельной странице `muzhskoj-manikyur.html`. Мужской педикюр и комплекс сохраняются в выборе. В общем калькуляторе опции нет. Запись мужского ухода — только через Telegram Венеры.

## Формула

Политика `individualVisit.mode = maximum-time-rate`. Для каждого мастера из `individualVisit.masters` берётся максимальная стоимость минуты среди опубликованных обычных услуг: `r = max(price / min)`. Мужской уход исключён из альтернативного обычного потока.

За длительность выбранных услуг `T` стоимость резервирования времени каждого мастера: `R = ceil(r × T)`, с округлением вверх только до целого рубля. Длительные альтернативные процедуры учитываются пропорционально времени визита. Нельзя добавить к 45 минутам цену целого наращивания или нескольких процедур, заканчивающихся после ухода клиента.

Для выбранного мастера доплата равна `max(0, R − P)`, где `P` — уже оплаченные выбранные услуги. Для остальных мастеров доплата равна `R`. Итог — `P + сумма доплат`. Работа выбранного мастера не оплачивается дважды, при высокой цене выбранной услуги доплата другого мастера не уменьшается.

Это максимальный тариф за время визита по текущему каталогу, без вероятностей спроса, маржинальности и проверки реального расписания. Он не является расчётом фактически потерянной выручки. Дату и отсутствие других посетителей подтверждает Венера.

## Текущий пример

Мужской маникюр — 1 700 ₽ / 45 минут.

- Венера: максимальная ставка 3 300 ₽ / 60 мин; за 45 мин — 2 475 ₽; доплата после вычета маникюра — 775 ₽.
- Юлия: максимальная ставка 1 800 ₽ / 60 мин; за 45 мин — 1 350 ₽.
- Доплата — 2 125 ₽. Итого — 3 825 ₽.

Пример пересчитывается по актуальному каталогу, не является отдельной фиксированной наценкой.

## Полнота данных

Для выбранных услуг нужны цена и длительность; для дополнений также нужна длительность. Скрытые и архивные услуги исключаются. Отсутствующие или некорректные данные дают «по запросу», а не числовой тариф.

Из переданного фрагмента восстановлены предварительные значения: маникюр — 1 700 ₽ / 45 мин; педикюр — 3 000 ₽ / 75 мин; комплекс — 4 700 ₽ / 120 мин. В источнике они прямо обозначены как ориентиры до утверждения Венерой. Все три имеют `priceStatus: verify-with-master`. Прайс Юлии также требует подтверждения, поэтому расчёт предварительный (`≈`). Полный архив старого чата не получен.

## Проверки

Node-тест проверяет пропорциональную стоимость длительной услуги, отсутствие двойной оплаты, округление, неизвестные значения, скрытые услуги и конкретный расчёт текущего каталога. Браузерный тест проверяет цены и время всех трёх мужских услуг, доплату 2 125 ₽, итог 3 825 ₽ и заявку Telegram. Индивидуальная опция исчезает у педикюра и комплекса и отсутствует на главной.
