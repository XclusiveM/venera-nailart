## Дополнение: проверки и изменения по запросу владельца (22.10.2026)

- `caa1bf58`: smoke-тест проверяет наличие `#copyRequest` до вызова `is_enabled`. Необязательная кнопка при отсутствии пропускается с сообщением.
- `fde4427`: рассмотрены вызовы `innerHTML` в `assets/site.js`: `openSheet` использует шаблон из `INFO` и каталога; название и тексты проходят через `esc`, URL теперь проходят `safeHref` (допустимы только HTTP(S), кавычки экранируются). `esc` использует DOM `textContent` и затем получает безопасную HTML-строку. `giftOpts` очищается `replaceChildren`; строка согласия на Метрику — константа без пользовательских значений. Поле комментария и поля сертификата выводятся через `textContent`, `canvas.fillText` и `encodeURIComponent`, не через HTML.
- `2f67b58`: smoke-тест проверяет 320/390/768/1440 px на каждой HTML-странице в Chromium и, при наличии, WebKit. После фактического запуска сохраняет `artifacts/overflow-results.csv` с `browser,page,viewport_px,scroll_width_px,result`.
- `e12aed3`: `sync_catalog.py --check` выводит `файл:строка` для старой цены, если цена в прежнем встроенном каталоге изменилась и старое значение не используется ни одной текущей услугой. Это **не полная гарантия** обнаружения всех произвольных упоминаний, особенно общих сумм.
