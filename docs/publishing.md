# Публикация прайса и админ-панель

## Что уже подключено
- `data/services.json`: каталог услуг, категорий и дополнительных опций.
- `assets/site.js`: клиентский калькулятор читает каталог, с резервным встроенным прайсом.
- `scripts/sync_catalog.py`: проверка структуры и обновление встроенного прайса и HTML-таблиц.
- `.github/workflows/publish-catalog.yml`: при изменении каталога запускает синхронизацию и коммитит HTML.
- `admin-preview/`: открытые демонстрационные редакторы, **без входа и без публикации**.

## Публикация изменений сейчас
1. Измените `data/services.json` в GitHub и сохраните коммит в `main`.
2. Проверьте вкладку Actions → «Обновление прайса на сайте»: запуск должен завершиться успешно.
3. Проверьте коммит с обновлением HTML. Проверьте GitHub Pages и фактические цены на сайте.
4. При ошибке публикации не считайте изменения завершёнными: проверьте логи и верните предыдущую версию файла.
5. Если GitHub Pages публикуется отдельным workflow, учтите: коммиты от `GITHUB_TOKEN` могут не запускать другие workflows. Настройте отдельный Pages deployment в этом же workflow или другой поддерживаемый триггер и проверьте его.

## Ограничения и риски
- Редакторы `admin-preview` публично доступны, это **не административная авторизация**. В них нет секретов или токенов; нельзя добавлять GitHub PAT в клиентский код.
- Для публикации из кабинета требуется доверенная серверная часть или авторизованный GitHub App/OAuth workflow с проверкой прав, аудитом и защитой от CSRF.
- Публичный сайт пока содержит дополнительные маркетинговые и SEO-тексты с конкретными ценами, которые могут не обновляться автоматически. Требуется полный аудит.
- Подключение аналитики и индексации требует решения владельца и проверки требований к данным и согласию.
- Фотографии нельзя удалять без проверки ссылок и использования на других страницах.
- До выпуска: проверить GitHub Actions, реальный Pages deployment, мобильные браузеры, калькулятор, таблицы, ссылки и откат.

## Запуск вручную локально
```sh
python3 scripts/sync_catalog.py --check
python3 scripts/sync_catalog.py --write
node --check assets/site.js
```

## Следующий обязательный релиз
Безопасная панель управления: серверная авторизация, загрузка фотографий, редактирование услуг, страниц и SEO, предварительный просмотр, публикация с подтверждением и восстановление версий.
