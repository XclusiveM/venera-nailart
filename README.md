# Венера, ногтевая студия — сайт

Сайт ногтевой студии с несколькими мастерами в Новых Ватутинках (6-я Нововатутинская, 5). **Не публиковать без согласия мастера.** Сейчас все страницы закрыты от индексации (`noindex`, `robots.txt: Disallow`). Заполнение `business.site_url` **не** снимает `noindex` автоматически. Публикация и открытие индексации допускаются только после проверки и отдельного разрешения.

## Как устроено
- `src/data.json` — **единственное место** для цен, услуг, контактов, реквизитов ИП, номера Метрики, адреса сайта.
- `src/info.json` — тексты «что это / откуда пошло / кому подходит» для каждой услуги.
- `src/build.py` — собирает все HTML-страницы в корень репозитория. HTML руками не править.
- `src/partials/` — вспомогательные схемы; крупная мультяшная стопа из главного интерфейса убрана.
- `assets/site.css`, `assets/site.js` — стиль и все модули (каждый модуль проверяет свою разметку и не ломает остальные).
- `assets/fonts/` — Tenor Sans и Golos Text (woff2).
- `tests/check_site.py` — ссылки, якоря, noindex, внешние ресурсы, запрещённые формулировки, JSON-LD, актуальность сборки.
- `tests/smoke.py` — браузерная проверка (Playwright): 360/390/768/1440, ошибки JS, скролл вбок, подбор формы/оттенка, калькулятор, темы ухода за стопами, маршруты, сертификат.

## Работа
```bash
python3 src/build.py          # собрать
python3 tests/check_site.py   # проверить
pip install playwright && python -m playwright install chromium webkit && python3 tests/smoke.py
```
Изменения — через отдельную ветку и pull request; CI прогоняет все проверки.

## Перед запуском (заполнить в src/data.json)
- `legal`: ФИО ИП, ОГРНИП, ИНН — строка появится в подвале.
- `hours`: часы работы.
- `metrika_id`: номер счётчика Яндекс Метрики — появится плашка согласия.
- `site_url`: адрес сайта — подготавливает canonical и sitemap.xml. `noindex` и `robots.txt` менять только после разрешения на запуск.
- Цены мужских услуг (`price: null` → число).
- Тексты политики и согласия проверить у юриста, заполнить поля в квадратных скобках.

## Подтвердить у мастера
Имя (Венера / Юлия в Bumpix), мужские услуги и цены, состав «вросший ноготь 1 000 ₽», условия сертификатов (оплата, срок, номер), часы, фото работ.

## Мастера и запись в Bumpix

В файле `src/data.json` есть массив `booking_profiles`. Каждая запись содержит:
- `id`: стабильный технический идентификатор мастера.
- `label`: подтверждённое имя / роль на сайте.
- `url`: персональная ссылка на Bumpix.
- `active`: `true` — показывать профиль, `false` — скрыть без удаления истории.
- `confirmed`: есть ли подтверждение, кому принадлежит профиль.
- `detail`: внутреннее описание для сопровождения.

Сейчас: [Венера](https://bumpix.net/188382), а на её странице в блоке «Работают со мной» есть [Юлия](https://bumpix.net/463374), мастер маникюра. Прямая страница Юлии не была проверена на текущие услуги, цены и свободные окна, поэтому этих сведений не копировать в сайт без согласования.

**Если появляется новый мастер:** добавить элемент в `booking_profiles`, получить подтверждение ссылки и имени, проверить `active`, запустить `python3 src/build.py`, затем `python3 tests/check_site.py` и браузерные тесты. Если мастер уходит — поставить `active: false` и пересобрать. Изменять имена профилей в одном месте, не копировать ссылки по разным страницам.

Сайт не подключён к приватному API Bumpix и **не узнаёт автоматически** о приёме, увольнении, расписании или изменении прайса. Ссылки ведут в Bumpix, где пользователь проверяет актуальное время. В черновой ветке включена автоматическая генерация HTML из `src/data.json`; публикация из `main` отдельно контролируется владельцем.

Не использовать цены одного мастера как гарантированные цены всех специалистов. Не размещать медицинские обещания, подтверждение лицензий и фото чужих работ без проверки.
