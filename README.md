# Венера, ногтевая студия — сайт

Сайт мастера маникюра в Новых Ватутинках (6-я Нововатутинская, 5). **Не публиковать без согласия мастера.** Все страницы закрыты от поисковиков (`noindex`, `robots.txt: Disallow`), пока в `src/data.json` не заполнен `business.site_url`.

## Как устроено
- `src/data.json` — **единственное место** для цен, услуг, контактов, реквизитов ИП, номера Метрики, адреса сайта.
- `src/info.json` — тексты «что это / откуда пошло / кому подходит» для каждой услуги.
- `src/build.py` — собирает все HTML-страницы в корень репозитория. HTML руками не править.
- `src/partials/` — SVG схемы маршрута и стопы.
- `assets/site.css`, `assets/site.js` — стиль и все модули (каждый модуль проверяет свою разметку и не ломает остальные).
- `assets/fonts/` — Tenor Sans и Golos Text (woff2).
- `tests/check_site.py` — ссылки, якоря, noindex, внешние ресурсы, запрещённые формулировки, JSON-LD, актуальность сборки.
- `tests/smoke.py` — браузерная проверка (Playwright): 360/390/768/1440, ошибки JS, скролл вбок, примерка, калькулятор, стопа, маршруты, сертификат.

## Работа
```bash
python3 src/build.py          # собрать
python3 tests/check_site.py   # проверить
pip install playwright && python -m playwright install chromium webkit && python3 tests/smoke.py
```
Изменения — через отдельную ветку и pull request; CI прогоняет все проверки.

## Перед запуском (заполнить в src/data.json)
- `legal`: ФИО ИП, ОГРНИП, ИНН — строка появится в подвале.
- `hours`: часы работы.
- `metrika_id`: номер счётчика Яндекс Метрики — появится плашка согласия.
- `site_url`: адрес сайта — появятся canonical, sitemap.xml, robots.txt откроет индексацию. После этого убрать `noindex` в `head()`.
- Цены мужских услуг (`price: null` → число).
- Тексты политики и согласия проверить у юриста, заполнить поля в квадратных скобках.

## Подтвердить у мастера
Имя (Венера / Юлия в Bumpix), мужские услуги и цены, состав «вросший ноготь 1 000 ₽», условия сертификатов (оплата, срок, номер), часы, фото работ.
