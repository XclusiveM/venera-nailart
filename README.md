# Венера, ногтевая студия — сайт

Сайт студии в Новых Ватутинках, 6-я Нововатутинская, 5. Публикация и открытие индексации — после отдельного разрешения владельца/мастера. Сохранять `noindex` и `robots.txt: Disallow` до запуска.

## Источники и сборка

- `data/services.json`: услуги, категории, дополнительные опции и политика индивидуального визита. `master` разделяет прайсы Венеры (`venera`) и Юлии (`julia`); ID услуги не меняется при переименовании.
- `scripts/sync_catalog.py`: обновляет встроенный резервный каталог на страницах, существующие таблицы и полный прайс `ceny.html`. Полный прайс генерируется по мастерам и категориям.
- `src/info.json`: описания процедур; `src/portfolio.json`: каталог фотографий.
- `assets/site.js`: калькулятор, подготовка Telegram-заявки и остальные интерактивные модули.
- `assets/booking-pricing.js`: расчёт максимального тарифа индивидуального визита; подробности — `docs/individual-visit.md`.
- Старые `src/data.json` и `src/build.py` удалены в предшествующей рабочей ветке. Не восстанавливать прежнюю независимую базу цен и генератор.

```sh
python3 scripts/sync_catalog.py --write
python3 tests/check_site.py
python3 tests/price_mutation.py
node --check assets/site.js
node --check assets/booking-pricing.js
node tests/booking_pricing.cjs
python3 tests/smoke.py
```

Для smoke-тестов нужны Python Playwright и установленный Chromium. Если установлен WebKit, он также проверяется. Отчёт по 320/390/768/1440 px и снимки сохраняются в `artifacts/` и не коммитятся. CI устанавливает оба браузера.

Изменения — в отдельной ветке и pull request. Каталог синхронизировать и проверять до коммита. Синхронизация таблиц не гарантирует обновления всех произвольных цен в FAQ, метаданных и JSON-LD; проверка `price_mutation.py` подтверждает обнаружение конкретной устаревшей цены.

## Запись

Венера: https://bumpix.net/188382, Юлия: https://bumpix.net/463374. Ссылки открывают профиль выбранного мастера. Расписание, персонал и прайс Bumpix не синхронизируются автоматически.

Мужские услуги и индивидуальный визит оформляются подготовленной заявкой в Telegram Венеры (`Venera_Ni` — контакт из текущего проекта). Выбор желаемого дня/части дня — пожелание; дату и условия подтверждает Венера. Калькулятор не создаёт бронь и не отправляет сообщение самостоятельно.

Мужские цены и длительности в репозитории пока `null`; они не заменены выдуманными числами. Цены Юлии помечены `verify-with-master`, выводятся как предварительные. При отсутствии данных для полного индивидуального тарифа показывается запрос цены, а не частичный итог под видом полного.

## Перед запуском

Проверить контакт Telegram, актуальный прайс и длительности, условия индивидуального визита, часы работы, реквизиты и тексты политики/согласия, условия сертификатов и права на фото. Эти сведения нельзя считать подтверждёнными только по наличию исходников. Не добавлять клиентские токены в публичную админку `admin-preview`.
